# 班級知識王積分系統 v1.4

全新獨立 Flask 班級知識王系統，不連接舊版 class-score-system 或 quiz-battle。

## v1.4 題庫架構
- 正式採用「題庫 → 單元 → 題目」架構。
- 同一道題可以加入多個題庫，不必複製題目。
- 教師後台可新增題庫、建立單元、手動新增題目、搜尋與刪除題目。
- CSV 匯入支援「題庫、單元、科目、年級」欄位；舊版「分類」欄位仍可相容，會把分類當成題庫名稱。
- CSV 匯入時，如果題目內容、選項與正確答案相同，系統會沿用既有題目並加入新的題庫/單元。
- CSV 匯出會保留題目所屬的多個題庫關係。
- 是非題使用 O / X。
- 題庫與題目關聯資料存入 PostgreSQL。

## AI 對戰選題
- 學生按 AI 對戰後，可複選一個或多個題庫。
- 可以再勾選指定單元；選了單元後，只從所選單元抽題。
- 最多抽 10 題。
- 未選單元時，從所選題庫的全部題目抽題。

## HP / 積分規則
- 對戰開始保留學生原有 HP，不重設成 100。
- 答錯：HP -10。
- AI 對戰獲勝：本場總得分 100% 轉成 HP。
- AI 對戰落敗：本場總得分 50% 轉成 HP。
- 真人對戰沿用相同的 HP 結算規則。
- HP 不自動換成班級積分。
- 手動兌換：1000 HP → 1 班級積分。
- 手動補充練習：1 班級積分 → 10 HP。

## 其他功能
- 20 分抽一次寶物卡。
- 教師可管理留言、查看學生容易錯的題目與正確答案。
- 真人對戰 2 人滿房後自動開始。
- 離開真人房間會清理玩家與空房。

## Render
Build Command: `pip install -r requirements.txt`
Start Command: `gunicorn app:app`

### PostgreSQL
Render Web Service 的 `DATABASE_URL` 請使用 Render PostgreSQL 的 Internal Database URL。
不要因程式更新重新建立資料庫；現有資料會留在 PostgreSQL。

## CSV 範本
請參考 `題庫匯入格式_v2_範本.csv`。

欄位：
`題庫,單元,科目,年級,題型,秒數,題目,選項一,選項二,選項三,選項四,正確答案`

正確答案使用選項編號：1、2、3、4。是非題使用 O / X，正確答案為 1 表示 O，2 表示 X。
